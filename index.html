متجر عطور فاخر — Next.js 15 + Firebase

متجر إلكتروني كامل بالعربية (RTL) والإنجليزية: واجهة ليلية فخمة، لوحة إدارة آمنة، سلة ودفع، تتبّع طلبات، فاتورة قابلة للطباعة PDF، وإرسال الطلبات مباشرة إلى واتساب المالك.

🛍️ افتح المتجر الشغّال الآن 🔐 لوحة الإدارة ⬇️ تحميل المشروع ZIP

ملحوظة: رابط المتجر مؤقّت (نفق تجربة) ويتبدّل عند إعادة تشغيل جهازي — راجع صفحة الـ README أو اسألني عن الرابط الجديد.

● نسخة تجريبية شغّالة حاليًا
🛒 دفع عربي RTLسلة، كوبونات، شحن وضريبة محسوبة على الخادم، وموجّه كامل.
💬 واتساب فوريعند إتمام الطلب يُفتح واتساب برسالة الطلب جاهزة، بدون كشف الرقم.
🧾 فاتورة PDFمستند فاخر بقطعة ذهبية وعلامة مائية، صفحة واحدة عند الطباعة.
🔐 أمان على الخادمجلسات HttpOnly موقّعة، إبطال فوري عند تغيير كلمة المرور، تحديد معدّل المحاولات.
👥 لوحة إدارة كاملةمنتجات، طلبات، عملاء، صلاحيات موظفين، سجل تدقيق، وتصدير CSV.
🌍 عربي/Englishتبديل لغة كامل مع RTL/LTR تلقائي.

⚠️ لماذا لا يعمل المتجر هنا مباشرة؟

هذه الصفحة مستضافة على GitHub Pages وهي خدمة ملفات ثابتة فقط (HTML نصية). متجر VELUNORA تطبيق Next.js بخادم Node (واجهات API + جلسات + قاعدة بيانات)، لذلك يحتاج خادمًا حقيقيًا للتشغيل.

  • عرض سريع الآن: زر «افتح المتجر الشغّال» أعلاه (نفق مؤقت على جهاز المالك).
  • تشغيل دائم: VPS أو أي مزوّد يدعم Docker — المشروع يحتوي Dockerfile وrender.yaml جاهزين.
  • نشر سحابي: Vercel مع STORAGE_DRIVER=firebase (يتطلب مشروع Firebase).
